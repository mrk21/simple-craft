# ブロックテクスチャ

全体索引は [design.md](design.md)。
新しいブロックを追加する具体的手順は skill [add-block](../.claude/skills/add-block/SKILL.md) を参照。

## 仕様

- 解像度: 16×16 px（標準的な Minecraft 仕様）
- 形式: PNG（アルファチャンネル付き）
- 描画: `NearestFilter` でドットを保つ

## simple-craft の構成

| ブロック | 面構成                     | 透明度 |
| -------- | -------------------------- | ------ |
| 草       | 上面・下面・側面 の3種     | 不透明 |
| 石       | 全面共通 1種               | 不透明 |
| 砂       | 全面共通 1種               | 不透明 |
| 水       | 全面共通 1種（後でアニメ） | 半透明 |

合計 6 テクスチャ + 水のアニメフレーム。

## AI 生成時のプロンプト指針

- 「シームレスにタイリングできる」
- 「16×16 ドット絵風」
- 「アルファ付き PNG」
- 草の上面は**最初から緑色で出力**（バイオーム tint は実装しない）

## バイオームカラー（不採用）

本家は灰色テクスチャ × バイオーム色で表現するが、simple-craft はバイオームがないので採用しない。テクスチャ自体を最終色で書き出す。

## アトラスについて

アトラスへのパッキング・UV 計算・mipmap 設定は描画側の関心事。詳細は [rendering.md](rendering.md) 参照。
